# HASHCODE Community Portal

Portail communautaire — gestion des membres, pôles et événements.

## 🚀 Démarrage rapide

```bash
npm install
cp .env.example .env.local
npm run dev
```

## 📦 Publication sur GitHub

```bash
# 1. Crée le repo sur github.com (sans README)
# 2. Puis :
./scripts/publish.sh

# Ou manuellement :
git init -b main
git add -A
git commit -m "feat: publication initiale"
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```
