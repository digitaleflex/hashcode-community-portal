## 📦 Installation

```bash
git clone https://github.com/<ton-user>/hashcode-community-portal.git
cd hashcode-community-portal
npm install
cp .env.example .env.local   # configure DATABASE_URL + JWT_SECRET
npm run dev
```

## 🗂️ Structure

```
app/            → routes Next.js (App Router)
lib/            → auth, db, utils
components/     → UI réutilisable
docs/           → documentation & audits
scripts/        → migrations & outils
```
